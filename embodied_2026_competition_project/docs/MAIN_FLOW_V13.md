## 1. main与路线循环

```mermaid
flowchart TD
    A["启动 main.py"] --> B["完整配置及模型检查"]
    B --> C["连接设备；新场次自动张爪和收臂"]
    C --> D["开始或沿用原600秒时钟"]
    D --> E["新场次导航 initial_pose 和 entry"]
    E --> F["清旧障碍；按配置顺序选择待查点"]
    F --> G{"到优先离场时刻？"}
    G -->|是| X["保留可能负载；收臂离场"]
    G -->|否| H{"本轮有下个点？"}
    H -->|是| I["检测点导航：首次加1次重试"]
    I --> J{"实际到达？"}
    J -->|是| K["头部全物品播报；腕部观察抓一件"]
    J -->|否且接口在线| L["只跳过本轮；下轮重查"]
    K --> M["有物先投放；空爪恢复后换点"]
    M --> N["记录结果；推进配置游标"]
    L --> N
    N --> F
    H -->|否| P{"仍有待查点？"}
    P -->|是| Q["等3秒；清临时受阻状态及旧代价图"]
    Q --> F
    P -->|否| X
```

配置/设备准备失败发生在开始前；initial/entry重试失败允许暂停。恢复已完成入场时不回起点，先核对负载及保存的剩余回程，再续投或接当前路线。default起点导航与--set-initial-pose发布定位是两件事。

当前软截止535秒，计算为 `600-max(30,45+20)`。每阶段都受更早的点内/动作/软/硬截止约束；离场只屏蔽软截止，不屏蔽600秒或主动停止。未知参数错误按文件/键/行号报告，不能吞成点位无物品。

## 2. 家具观察与一件抓取

```mermaid
flowchart TD
    A["头部识别；播报全部稳定实例和同类数量"] --> B{"抓取场景"}
    B -->|surface| C["桌面主位及已填备用位"]
    B -->|shelf| D["柜层 mid→high→low；每层主位和备用位"]
    B -->|ground| E["地面主位及备用位；观察稳定等3秒"]
    C --> F["腕部多帧采图；深度及地面角度；补报不等播放"]
    D --> F
    E --> F
    F --> G{"有有效候选？"}
    G -->|是| H["选一件；过期则原位重测；保存实例与回程"]
    H --> I["按对应路径前伸；闭爪加紧；抬起或退出；收臂"]
    I --> J{"最终三指反馈"}
    J -->|稳定受阻| K["确认持物；抓取计数去重"]
    J -->|新鲜但不稳定或未知| L["保守疑似持物；不加确认计数"]
    K --> M["返回投放点"]
    L --> M
    J -->|稳定空爪| N["本点阈值内再观察；超时恢复换点"]
    G -->|否| O{"所有视角已完成且头腕均无框？"}
    O -->|是| P["本轮完整空观察；连续两次才退休点"]
    O -->|否| N
```

桌面保留坐标变换及抬起/回程；柜层保留v2中间点、抓取点、抬起和退出；地面保留catch_ty横移、前伸、下降、75/100闭爪后直接home。它们分别在pick及coordinates模块，当前修订没有重写物理公式。

候选不稳定、深度无效、过期、观察位未到达、抓空、软件异常，都不是判空依据。到点总阈值桌/柜120秒、现有地面180秒。超时离开旧计时器再复位，空爪提前张开/收臂，疑似持物保留并续投。原位备用观察姿态会轮换；底盘多点按配置顺序重新导航和拍照，reposition_points关系不触发立即插队。

6750边界不暂停；稳定受阻才计确认抓取，新鲜不稳定只保守携带。动作结果状态3、新鲜有效位姿存在时，附加15mm/5°误差只提示。持续无反馈仍需设备诊断，不用旧XYZ猜坐标。

## 3. 投放与离场优先

```mermaid
flowchart TD
    A["保存负载；已收臂；DROP_NAV"] --> B{"实际drop到达？"}
    B -->|是| C["直接PUT；不读取holding"]
    C --> D["到place；张爪；确认open；先保存回执"]
    D --> E["收臂；确认记录去重；下一点"]
    B -->|否且接口在线| F{"次数及120秒窗口仍允许？"}
    F -->|是| G["停底盘等5秒；清图和更新；同drop重试"]
    G --> A
    F -->|否| H["当前收臂处提前张爪确认；home；记弃物"]
    H --> I["下一检测点；不计交付"]
    A -->|535秒优先离场| X["保留可能负载；必要回程和收臂"]
    X --> Y["导航exit"]
    Y --> Z{"到达exit？"}
    Z -->|是| S["FLOW_COMPLETED；离场到达true"]
    Z -->|否且接口在线| T{"到600秒？"}
    T -->|否| W["停底盘等5秒；清图更新后再试exit"]
    W --> Y
    T -->|是| V["TIME_UP；未到达不伪报成功"]
```

DROP共3次、总120秒包含导航/等待/清图，任一先到结束。到drop直接PUT，只在释放后确认张开；已释放但home失败恢复不重复释放；软截止离场及总截止收尾也会补登记已完成释放的回执一次。疑似持物也执行PUT但不计确认交付，区内落点和途中未滑落没有独立传感器证明。

时间不足优先离场可持物、可0交付；它不会先去下一家具，也不因软截止主动弃物。收臂是底盘继续移动的必要执行步骤，硬件持续无法收臂仍可能暂停。离场失败不安排转圈示意，move_base是否旋转看其恢复/控制日志。

## 4. 特殊情况与恢复

```mermaid
flowchart TD
    A["异常或阶段到时"] --> B{"故障类型"}
    B -->|参数| P["文件及键和可定位行号；拒绝或暂停"]
    B -->|主动停止| S["保存；取消本目标；请求零速；暂停"]
    B -->|点内软件或短暂反馈| C["退出旧阶段计时器；限时复位"]
    C --> D["取消旧目标；新鲜反馈；剩余保存回程；home"]
    D --> E{"恢复完成？"}
    E -->|是| F["空爪换点；可能持物续投；到软截止离场"]
    E -->|否| G["通信复核10秒；普通复位限次；最小恢复30秒"]
    G --> H{"持续执行或通信不可达？"}
    H -->|是| Q["设备或执行故障暂停；排障后原场resume"]
    H -->|否| F
    B -->|相机采图或断连| R["限次重启；每准备最多60秒"]
    R --> H
    B -->|推理或回包软件| C
    B -->|调度状态| U["5秒内重建访问状态；物理编号去重保留"]
    U --> F
    B -->|记录盘或保存| V["后台2秒等待；备用目录；提醒继续"]
    V --> F
```

复位普通最多两次，各30秒，失败复核设备10秒、两次间隔2秒；最后独立最小恢复仍30秒。不是无限恢复等待。持续未取消/未收臂/未开爪不能伪造travel_ready。C扩展信号延迟、硬杀/OOM/断电、持续未覆盖软件损坏不保证自动继续。

模块分工：main入口与错误输出；RobotSession设备、时钟和checkpoint；Workflow路线/投放/离场；PointScheduler配置順序/完整判空；Recovery通信及有限复位；Actions负载/回程，独立pick/grasp/put/release执行。详细文件清单见[UPDATE_V13.md](UPDATE_V13.md)。三级开门/抽屉接口保留未启用，本图的正常抓取是一级/二级，不自动重复未确认开门。
