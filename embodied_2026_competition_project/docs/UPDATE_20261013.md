# 2026-10-13 修改说明

本次基于 GitHub `main` 的 `7ad6509` 修改，延续已有最后30秒离场和播报并行逻辑。

## 本次行为

1. **点位剩余数量**：`detection_points[].object_count` 默认1，允许非负整数；0表示不搜索该点。按列表顺序遍历，确认抓取后减1，减至0退出搜索队列；失败不减，下轮重新导航到该点。
2. **成功只计一次**：夹爪确认成功的物品ID才扣减。疑似负载不扣，同一次抓取在抓取后、投放前重复登记也只扣一次。数量为0仍先完成当前物品的投放。
3. **恢复保留剩余数量**：调度快照升级为版本3，保存 `remaining_count`、`counted_object_ids`。旧版本2按实际 `confirmed_object_ids` 迁移，旧判空和访问次数不会把点位永久移除。新场次从配置数量开始，恢复同场沿用原数量和原截止时间。
4. **腕部自主选物**：桌面用原 `TARGET_NAMES` 18类选物；地面用配置的全部腕部类别。Kinect 的类别和空检测只作为播报/记录信息，不把腕部限定为该类别。显式排除列表继续生效，柜层原有自主选物规则保留。
5. **模型复用**：`realsense_yolo11_ref.py` 和 `realsense_yolo11.py` 按绝对权重路径、设备缓存模型。准备阶段预加载启用点位所需模型；桌面/柜层同一模型复用。恢复已进入离场窗口时跳过抓取模型预加载。
6. **每点每轮一次完整抓取**：取消主流程在同一底盘位置立即重复整段抓取。失败后继续下一点，下轮重新到位；原脚本的采图重试、柜层搜索、完整合爪和收臂保持原样。
