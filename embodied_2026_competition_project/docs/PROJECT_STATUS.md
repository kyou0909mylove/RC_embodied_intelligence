## 仍可暂停/拒绝

启动参数/恢复记录损坏、重复实例；初始/入场导航重试失败；持续模块通信/采图不可达；常规及最小恢复后仍不能实际取消/收臂或张爪；Ctrl+C/stop/ROS关闭。极端未覆盖程序损坏也可能走最后异常防线。600秒是TIME_UP正常截止，不无限恢复。
